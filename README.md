## ✨ Features

* **Custom Neomorphic UI:** A highly polished, responsive interface with custom interactive containers and smooth animations.
* **State Management & Architecture:** Built on a robust foundation using Feature-Driven Clean Architecture, BLoC/Cubit, and GetIt for dependency injection.
* **Localization (l10n):** Full bilingual support (English and Ukrainian) with smooth, animated on-the-fly language switching.
* **Cloud Integration:** Secure CV PDF retrieval and download powered by a public Supabase Storage bucket.
* **Secure Environment:** Sensitive credentials (API keys, Supabase URLs) are securely managed using `flutter_dotenv`.
* **Type-Safe Routing:** Declarative and strictly typed navigation using `go_router`.

## 🛠 Tech Stack

* **Framework:** Flutter & Dart (Mobile & Web)
* **Architecture:** Clean Architecture, BLoC / Cubit
* **Dependency Injection:** GetIt
* **Routing:** GoRouter
* **Backend / Cloud:** Supabase (Storage)
* **Security:** `flutter_dotenv`
* **UI/UX:** Neomorphic design, `flutter_inset_shadow`
* **Utils:** `url_launcher` (external routing)
